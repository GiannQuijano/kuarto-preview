Weekend test plan

Launch Friday, read Monday.

Campaign
Leads objective, one campaign for pool remodels, separate from the new-build pool campaign. Not a Special Ad Category (home improvement, not housing).
Ad set
One ad set, all 4 ads. Placements: Feed, Stories, Reels on Instagram and Facebook.
Budget
$100 to $200 a day for Fri to Sun. About $300 to $600 total to get a first read.
Audience
Ages 32 to 65. ZIP targeting around high-value neighborhoods (placeholder list: Newport Beach, Irvine, Laguna Niguel, Calabasas, Manhattan Beach, Palos Verdes, Rancho Santa Fe, Carlsbad, Pasadena). Start with Advantage+ audience using interests as suggestions: Architectural Digest, Dwell, Houzz, swimming pools, pool maintenance, home improvement. If you can, layer a list of ZIPs with a high share of homes with existing pools.
Tracking
Meta Pixel on the landing page. Fire a Lead event on form submit and a Schedule event when the Calendly booking completes.

What to watch

  1. Thumb-stop: link CTR above 1%. Below 0.6% after 2,000 impressions, pause the ad.
  2. Page: form starts from at least 8% of landing page views. If lower, the hero or offer needs work, not the ads.
  3. Booked calls: the real KPI. For a $20k to $75k remodel, a booked call under $75 to $150 is a healthy early signal.
  4. Keep the winner: on Monday move budget to the 1 or 2 ads with the lowest cost per booked call and swap in real project photos.

These benchmarks are starting points for a first test, not guarantees. Adjust once you see real numbers from the first weekend.

Before ads go live

Launch checklist.

  1. Replace placeholders on the landing page: license number, phone, service area, starting price, LED upgrade value and client quotes.
  2. Put the builder's Calendly link in BOOKING_URL and host the deployable page (files are in the project folder).
  3. Install the Meta Pixel and set up Lead and Schedule events.
  4. Confirm the offer terms with the builder: which lights the LED upgrade covers, which quarter it applies to, and what the 10 working days include.
  5. Upload the 8 ad images, paste copy, set the destination URL with UTM tags (utm_source=meta&utm_campaign=pool-remodel&utm_content=a/b/c/d).
